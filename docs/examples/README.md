# Examples

Worked examples, each run by Veriphy's test suite. The data is synthetic, made for the examples.

| Directory | Pack | Holds |
|---|---|---|
| `social-science/` | `social-science` | a survey, its analysis script, a thesaurus excerpt and the chapter's claims |
| `economics/` | `economics` | a table of real GDP and inflation, 2015 to 2024 |
| `econometrics/` | `econometrics` | a panel of 50 firms over 8 years: training and wages |
| `epidemiology/` | `epidemiology` | a trial of 240 patients: arm, age, months followed and deaths |
| `life-sciences/` | `life-sciences` | a coding sequence, a Gene Ontology excerpt and claims naming its terms |
| `genomics/` | `genomics` | a reference, reads aligned to it in SAM, and variant calls for two samples |
